🎨 Icon Library — SVG Icons as React Components
Коллекция SVG-иконок, преобразованных в типобезопасные React-компоненты с поддержкой SCSS-модулей, кастомных стилей и адаптивного дизайна.

Используется в проектах на Next.js (App Router) с Turbopack и SCSS Modules.

🚀 Как использовать
Импорт иконки
Все иконки экспортируются из центрального файла:
// src/assets/svg/index.ts
export { default as Logo } from './Logo.svg';
export { default as Search } from './Search.svg';
export { default as AddContact } from './AddContact.svg';
// ... и другие

🎨 Стилизация
Иконки — это обычные SVG-элементы, завёрнутые в React-компонент. Вы можете управлять внешним видом через:

✅ Поддерживаемые пропсы:
**className** Для подключения CSS-модулей или глобальных классов
**color** Меняет цвет иконки (работает, если в SVG fill="currentColor")
**style** Инлайновые стили (fontSize, width, height, color)
**width/height** Явный размер
**role, aria-label** Для доступности

# Пример SCSS-модуля:

.addContact {
color: blue;
font-size: 14px;

&:hover {
color: red;
}
}

Совет: используйте font-size вместо width/height для масштабирования — иконки ведут себя как текст (inline), и это даёт гибкость.

⚠️ Важно

1. Не используйте classNames — только className.
2. Цвет задаётся через color, а не fill.
3. Размер можно контролировать через font-size (рекомендуется) или width/height.
4. Иконки не содержат внутренних стилей — всё управляется извне.

🧪 Пример использования в кнопке
<button className={styles.btn}>
<Close />
</button>

.btn {
width: 42px;
height: 42px;
border-radius: 50%;
background: rgb(182, 181, 181);
border: none;
cursor: pointer;
display: flex;
align-items: center;
justify-content: center;
transition: all 0.3s ease;

&:hover {
transform: scale(1.2);
background: wheat;
}
}

✨ Добавляйте новые иконки только в формате очищенного SVG с fill="currentColor" для единообразия.
